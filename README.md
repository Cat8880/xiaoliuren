# 小六壬 · 掐指一算

一个单文件的网页占卜程序，用**小六壬掌诀**起课，带完整推演过程与断辞。
手机微信直接打开，无需安装、无需联网（除首次访问局域网）。

## 二、占卜原理（小六壬）

六宫循环顺序：**大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡**，数满六位回到大安。

| 宫位 | 神煞 | 五行 | 方位 | 数字 | 性 |
|---|---|---|---|---|---|
| 大安 | 青龙 | 木 | 东 | 1 5 7 | 吉·稳 |
| 留连 | 玄武 | 水 | 北 | 2 8 10 | 滞 |
| 速喜 | 朱雀 | 火 | 南 | 3 6 9 | 吉·速 |
| 赤口 | 白虎 | 金 | 西 | 4 7 10 | 凶·争 |
| 小吉 | 六合 | 木 | 东南 | 1 5 7 | 上吉·合 |
| 空亡 | 勾陈 | 土 | 中 | 3 6 9 | 空 |

**时辰起课（本程序默认）**

1. 从「大安」起正月，顺数到当前农历月 → 落宫 A
2. 从落宫 A 起初一，顺数到农历日 → 落宫 B
3. 从落宫 B 起子时，顺数到当前时辰 → 落宫 C，即为课象

例：农历三月、初五、午时
> 大安起正月 → 三月初：大安(1) 留连(2) **速喜(3)**
> 速喜起初一 → 初五：速喜(1) 赤口(2) 小吉(3) 空亡(4) **大安(5)**
> 大安起子时 → 午时(第7)：**大安**
> 结果：大安

**报数起课**：心中默念所问之事，随手报三个数，第一数自大安起数，第二数自上宫起，第三数同上，取第三落宫。

**两个传统细节**

- 子时（23:00–24:00）依例作**次日**之始，程序已按此处理并在首页标注「子时作次日」。
- 闰月按该月本身计（闰六月即作六月），不另加一位。

## 三、断辞来源

六宫总断、断曰四句、分项（谋事/求财/感情/健康/出行/寻人失物/官非口舌/文书考试）、
宜忌与应期，依传统小六壬口诀（大安事事昌、留连事难成、速喜喜来临、赤口主口舌、
小吉最吉昌、空亡事不祥）整理并译成现代说法。**同一宫问不同事，吉凶可以相反**
——比如空亡问病主虚惊、问官非主消散、问旧事主「该结束了」；程序里已按此分项区分。

## 四、文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | **成品**，单文件自包含，直接部署/打开用这个 |
| `src.html` | 源码模板（含 `__LUNAR_TABLE__` 占位符） |
| `lunar.txt` | 1950–2050 农历对照表（2127 字符，压缩编码） |
| `build.mjs` | 把农历表注入模板 → 生成 `index.html` |
| `gen_lunar.mjs` | 从 ICU 中文历重新生成 `lunar.txt`（改范围时用） |
| `serve.mjs` | 本机静态服务器（给手机访问） |
| `启动占卜.cmd` | Windows 一键启动 + 打印手机地址 |
| `cdp.mjs` | 无头 Chrome 自动验收（截图 + 交互断言） |
| `shots/` | 验收截图 |

改代码后：`node build.mjs` 重新生成 `index.html`。
